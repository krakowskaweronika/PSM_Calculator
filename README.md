## Dlaczego został wybrany ten kolor bazowy?
Kolor bazowy (#FF69B4) został wybrany ze względów estetycznych, gdyż nadaje aplikacji atrakcyjny wygląd, a jednocześnie idealnie pasuje do spersonalizowanego, pastelowego motywu przewodniego kalkulatora, harmonijnie współgrając z pozostałymi elementami interfejsu w obu trybach (jasnym i ciemnym).
